🎨 Designify — AI-Powered YouTube Thumbnail Generator

Designify is an AI-powered web application that helps creators generate **high-quality, eye-catching YouTube thumbnails** in seconds.  
It focuses on speed, creativity, and simplicity — so creators can spend less time designing and more time creating content.

🚀 Features

- 🎯 **AI Thumbnail Generation**
- 🖼️ Multiple **Thumbnail Styles** (Bold, Minimalist, Photorealistic, Illustrated, Tech)
- 📐 Supports multiple **Aspect Ratios** (16:9, 1:1, 9:16)
- 🎨 Custom **Color Schemes**
- 👀 **Live Preview Panel**
- ⬇️ **Download Generated Thumbnails**
- ⚡ Fast and responsive UI
- 🌙 Modern, clean design using Tailwind CSS

---
